    このサイトについて

    有志が作成した非公式のサイトです。文化庁および国の機関が 作成・運営するものではありません。内容の正確性について国は関与していません。

    間違いを見つけたら

    GitHub の Issue で受け取ります。アカウントが無ければ c4h-support@googlegroups.com へメールでも構いません。一覧の名称は原本のページに繋がっているので、その URL を添えていただけると確かめられます。

    表示・絞り込み・地図の不具合はこのサイトで直せます。名称・所在地などの 内容は「国指定文化財等データベース」にあるものをそのまま出していて、 こちらで書き換えることはしません — 元のデータそのものの誤りであれば、 出典元へ伝えていただくのが確実です。どちらか分からないまま知らせて いただいても構いません。
